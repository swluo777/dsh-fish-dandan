# 03 · 状态机与自主决策（decision）实施任务单

> 结构：同类插件怎么实施 → 优缺点 → 取舍 → 我们的设计 → 任务单。前置：`AGENTS.md`、`00`–`02`。

## 一、同类插件的自主行为实施机制（已核实）

| 插件 | 怎么实施自主行为 |
|------|------------------|
| dsh-proactive | 模型自定闹钟（once/interval/cron + **随机抖动**），冷会话按时唤醒；**静默时段 + 每日投递预算**；静默轮以 proactive_reclaim 结束并折叠为 tombstone；min_idle_seconds |
| dsh-cron | 有界 cron/interval，**每个任务绑定一个 session，不做全局调度** |
| dsh-goal | **粘性顶部 banner 保持当前目标可见**，agent 朝目标自主执行，支持人工 nudge |
| scheduled-tasks | every（≥5 分钟，**错过不重放**，只跑最新到期）/ cron（IANA 时区、DST 感知） |
| dsh-onebot-hub | when 四种调度表达式，按目标会话投递 |
| task-dispatcher | 对接滴答清单，定时拉取到期任务写入今日任务并通知 |

## 二、各方案优缺点

- **dsh-proactive**：防打扰与拟人化考虑最周全（抖动、预算、静默、空闲间隔）；缺点是只解决“何时唤醒”，不决定“醒来做什么”。
- **dsh-cron / scheduled-tasks**：边界清晰、可重放安全；缺点是机械定时，缺少内部状态驱动。
- **dsh-goal**：目标持续可见、自主推进、可人工纠偏；缺点是无精力/情绪概念，不会自己“想做什么”。
- **task-dispatcher**：与外部清单联动好；缺点是被动执行外部任务，非内生动机。

## 三、取舍

- **取**：绑定 session、静默时段、每日预算、随机抖动、最小空闲间隔、错过不重放、目标持续可见、人工 nudge。
- **去**：无状态的全局定时器、无预算轰炸、机械准点行为（不像人）、纯被动执行。
- **原则**：用“内部状态 + 状态机”决定做什么，用“有界、拟人化的调度”决定何时做，二者结合。

## 四、我们的设计

### 4.1 内部状态变量（随时间与事件变化）

| 变量 | 含义 | 变化来源 |
|------|------|----------|
| energy 精力 | 0–100，睡眠恢复、创作消耗 | 时间、行为 |
| mood 心情 | 0–100 | 互动反馈、事件成败 |
| boredom 无聊值 | 0–100，空闲累积 | 空闲计时 |
| socialNeed 社交需求 | 0–100 | 时间、亲密度 |
| creativeUrge 创作欲 | 0–100 | 灵感事件、特质 |

### 4.2 五状态及转移

状态：`睡眠 / 休息 / 自主探索 / 社交互动 / 专注创作`。

- 转移由状态变量阈值、当前目标（dsh-goal 式 banner）与记忆中的待办共同决定；
- 进入状态后选择对应行为：自主探索→刷抖音/B站并记录；社交互动→评论/回复/加互动；专注创作→画画/做视频；
- 决策结果写入记忆，行为成败反馈到状态变量。

### 4.3 调度约束

- 所有唤醒绑定具体 session，不做全局；启用静默时段、每日投递预算、随机抖动、min_idle_seconds；
- 错过的触发不重放，只跑最新到期；高风险/对外动作默认人工确认。

### 4.4 接口契约（`src/decision/index.js` 导出）

- `getInternalState()` / `tick(now)`：推进状态变量；
- `decideNext(context)`：依据状态机与目标返回下一状态与行为计划；
- `scheduleWake(plan)`：注册有界、带抖动的唤醒；
- `attach(ctx)`：挂载定时器与决策循环，用 `ctx.effect()` 保证卸载清理；
- 提供人工 `nudge(action)` 接口，可随时插入/覆盖当前计划。

## 五、验收标准

1. `node --check` 通过；五状态转移可被单测覆盖，含边界与回退；
2. 状态变量随时间/事件正确变化，日志可还原决策依据；
3. 唤醒满足静默时段、预算、抖动、最小空闲，且错过不重放；
4. 进入各状态能触发对应工具行为并把结果写入记忆；
5. 人工 nudge 可即时生效；插件卸载后无残留定时器；
6. 无密钥入库，不自动提交。

## 六、禁止事项

- 禁止全局/无界定时器与无预算对外投递；禁止绕过人工确认执行高风险动作；
- 禁止在决策模块直接改人格/记忆底层结构（只走其公开接口）；
- 禁止自动提交与未核实字段编码。
