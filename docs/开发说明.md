# dsh-fish-dandan 开发说明

## 目录结构

```
dsh-fish-dandan/
├── package.json          # 插件清单（ESM，dsh.bundle + dsh.client）
├── cordis.patch.yml      # 插件正式 bundle 的 patch
├── src/
│   ├── index.js          # 插件入口：装配人格 / 记忆 / 决策 / 平台 / GUI
│   ├── config.js         # 配置默认值与宽松校验
│   ├── persona/          # 01 人格：schema + 加载校验 + 系统提示词段落 + 首次见面
│   ├── memory/           # 02 记忆：存储 / 检索 / 衰减 / 复盘 / 上下文注入
│   ├── decision/         # 03 状态机 / 调度 / 决策 / 心情判断
│   ├── platform/         # 05 平台基座：契约 / 身份 / 路由 / 限流 / 设置
│   │   └── douyin/       # 06 抖音：登录 / 刷流 / 互动 / 私信监听 / 值班 / 发布
│   ├── stickers/         # 表情包库（上传 / 导入 / 远程装包）
│   ├── voice/            # 人味改写（发送前删 AI 腔）
│   ├── image/            # 豆包桌面版做图 + 文字卡片
│   ├── gui/              # 04 宿主半：/fish-dandan/api/* 与 /fish-dandan/ui
│   │   └── web/          # 网页版设置页（单文件 HTML/CSS/JS）
│   ├── client/           # 04 浏览器半：设置分区页面（手写 loader bundle）
│   └── utils/            # 日志、路径、JSON、文本、安全闸门
├── prompts/              # 值班剧本（网页可编辑）
├── persona/              # 人格模板（入库）
├── data/                 # 运行时数据（核心人格与公开设置入库；记忆/收件箱/登录态/日志不入库；data/share/ 是可分享的脱敏示例）
├── test/                 # node:test 单测与集成测试
└── docs/                 # 任务单、架构、调试脚本
```

## 本地挂载方式

DSH Desktop 启动时加载 profile：`%USERPROFILE%\.dsh\profiles\desktop`（Windows）或 `~/.dsh/profiles/desktop`（mac / Linux）。

在该 profile 的 `cordis.patch.yml` 末尾追加（路径必须为绝对路径，指向 .js，换成你自己的仓库位置）：

```yaml
- insert:
  - id: dsh-fish-dandan-dev
    name: /absolute/path/to/dsh-fish-dandan/src/index.js
```

重启 DSH Desktop 后，`data/plugin.log` 应出现：

```
插件加载开始
人格已加载：大肥鱼（来源：template）
人格段已注册（order=60）
记忆上下文已注册（order=4200）
决策循环已启动（每 60 秒推进一次）
GUI 接口已注册（数量以启动日志为准）（/fish-dandan/api/*），网页版：/fish-dandan/ui
插件加载完成：人格 / 记忆 / 决策 / 平台 / GUI 已装配
```

平台基座默认不连接任何适配器；开启 `platforms.enabled` 且注册了适配器后，才会出现连接日志。

浏览器半不需要单独构建：`package.json` 的 `dsh.client` 声明 + `./client` 导出会让客户端模块系统自动加载 `src/client/client.js`。网页版是宿主直接读 `src/gui/web/index.html`，改完刷新页面即可。

## 关键约束

- 瀑布事件必须调用 `await next()` 并返回其结果，否则会阻断 Agent；
- 所有注册走 `ctx`，插件卸载时自动清理；自有定时器用 `ctx.effect()` 提供释放函数；
- API Key 等密钥不进入插件代码，统一由 DSH 凭证层管理；
- 人格只能通过面板或受控接口修改，模型运行时不能自改；
- 记忆内容只追加，删除只做归档，所有变更留审计；
- 对外动作默认进待确认队列，`autoExternal` 保持 `false`。

## 排错

| 现象 | 先看哪里 |
|------|----------|
| 面板不出现 | `data/plugin.log` 是否有「GUI 接口已注册」；`settings.section` 是否注册成功（浏览器控制台看是否有 `[fish-dandan]` 报错） |
| 网页版打不开 | 宿主是否提供 `webServer`；地址是否为 `http://127.0.0.1:<端口>/fish-dandan/ui`；是否被非回环守卫拒绝 |
| 平台一直「未注册」 | 05 只提供基座，QQ/抖音/B站要等 06/07/08 适配器；`platforms.enabled` 默认关闭是预期行为 |
| 面板显示“连不上宿主” | 宿主是否挂载了 `webServer`；请求是否从非回环地址发起（默认拒绝） |
| 人格没生效 | 日志里是否有人格段注册；`data/persona/core-persona.json` 是否合法 JSON |
| 记忆检索不到 | 是否被隔离（面板“安全与审计”里能看到）；单词太短或没有共同 token |
| 状态不变化 | `decision.enabled` 是否为 `true`；`data/state/decision.json` 是否可写 |
