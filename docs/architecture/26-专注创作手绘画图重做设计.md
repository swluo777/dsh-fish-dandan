# 26 · 专注创作（手绘画图）重做设计

> 状态：实现完成，视觉 v4 已接入；12 张样张已全部用 v4 角色底稿重渲，等待负责人验收。旧版 `code-art / hand-drawn / journal-plan` 与 `assets/character/dandan/parts/` 已整体作废，
> 本文件描述从零重做的实现，不复用旧代码与旧样张。尚未提交 Git。

## 1. 目标与非目标

**目标**

- 「行为与调度 → 专注创作」重新可用：点「立即触发一次」能画出一张 1080×1440 的竖版手绘画。
- 同一入口同时接回三种调度语义：`自动`、`询问（需审批）`、`关闭`；手动触发不受这三档与频率上限限制（沿用现有语义）。
- 产物：桌面上一张 PNG + `data/creative/` 一份可回看的 HTML + 一条台账记录。
- 单张在普通 PC 上 10 秒内完成，不长时间占住行为调度。

**非目标**

- 不做动画、不接视频/Blender/ffmpeg/3D；**运行时不调用生图模型**。角色底稿是一次性制作的项目资产，绘制链路仍是纯本地 Canvas。
- 不改行为调度语义（状态机、预算、静默时段、待确认 TTL 全部沿用）。
- 不恢复旧 `parts/` 透明贴纸包，不把表情包原图贴进画面。

## 2. 输入模型

| 输入 | 来源 | 用法 |
|---|---|---|
| `vars`：energy / mood / boredom / socialNeed / creativeUrge | `decision.getInternalState()` | 决定画图心情、密度、物件数量、构图松紧 |
| `affect`：PAD / `mood.label` / `emotion` | 同上 | 情绪色调与表情倾向 |
| 当前主形象：`ageGroup` / `outfitId` / `displayName` / `id` | `characters.state()` | 角色比例、服装皮肤、落款称呼 |
| 当前表情包：`{id, emotion[], caption, intents[], avoid[]}` | 表情包库（优先最近使用，其次按心情检索） | 只取语义：姿态/动作/道具/情绪，不贴图 |
| 人格：`identity` / `speech` | `persona.current()` | 独白的口吻、自称、称呼 |
| 记忆（可选） | `memory` 检索 1–2 条 | 只影响文案情绪，不写隐私 |
| 随机种子 | 时间 + 计数器 + 历史索引 | 可复现，默认每次新 seed |

### 2.1 八种画图心情

在现有 PAD 八分体（`affect.js` 的 `OCTANTS`）与 `vars` 之上再落一层「画图心情」，不另造人格体系：

| key | 判定（优先级从上到下） | 表情 | 姿态 | 色调 | 线条 | 构图 | 环境 |
|---|---|---|---|---|---|---|---|
| `excited` 兴奋 | creativeUrge ≥ 70 且 energy ≥ 60 | 星星眼、张嘴笑 | 举手/尾巴翘 | 高饱和暖色 | 快、粗、抖 | 满、斜切 | 阳光、飞散小物 |
| `happy` 开心 | mood ≥ 65 且 PAD.p > 0 | 弯眼笑、腮红 | 蹦/挥手 | 暖黄+奶蓝 | 轻抖 | 开阔留白 | 桌面、云 |
| `proud` 得意 | PAD.d ≥ 0.25 且 mood ≥ 55 | 半眯眼、嘴角上扬 | 抱臂/抬下巴 | 对比强 | 重墨线 | 主体偏大、仰视 | 聚光、星星 |
| `calm` 平静 | 其余默认 | 垂眼、浅笑 | 坐/站 | 低饱和 | 稳、细 | 居中、大留白 | 白纸/墙面 |
| `blank` 发呆 | PAD.a ≤ -0.2 且 energy ≥ 35 | 瞳孔缩小、嘴微张 | 望云/坐着放空 | 灰蓝 | 细、断 | 高留白 | 云、窗、飞虫 |
| `sleepy` 困 | energy ≤ 35 | 闭眼、哈欠 | 站着打盹/蜷 | 低对比暖灰 | 软、慢 | 地平线低 | 枕头、夜、zzz |
| `wronged` 委屈 | PAD.p < -0.15 且 PAD.d < 0 | 下垂眼、抿嘴 | 抱膝/缩肩 | 冷色+一点暖 | 抖、重 | 小而偏角 | 雨、墙角 |
| `sad` 难过 | mood ≤ 35 或 PAD.p ≤ -0.4 | 低头、闭眼 | 背影/坐 | 冷灰 | 轻、断续 | 空旷、低 | 雨窗、冷便签 |

心情同时影响：物件数量、文字语气、纸张选择、草稿痕多少。

### 2.2 创作欲 `creativeUrge`

| 区间 | 密度 | 物件 | 颜色 | 构图冒险 | 草稿/涂改 |
|---|---|---|---|---|---|
| 0–30 | 低 | 0–2 | 2–3 色 | 保守居中 | 少 |
| 31–60 | 中 | 2–3 | 3–4 色 | 常规 | 中 |
| 61–100 | 高 | 3–5 | 4–5 色 | 偏心/斜切/出框 | 多 |

## 3. 画面计划（plan）

每张图先产出一个可解释、可复现、可验收的 plan，再交给渲染器：

```json
{
  "v": 1,
  "seed": 1731420000,
  "createdAt": "2026-11-15T12:00:00.000Z",
  "character": { "id": "child-initial-maid", "ageGroup": "child", "outfitId": "initial-maid", "displayName": "蛋蛋" },
  "mood": { "key": "blank", "label": "发呆", "tone": "calm", "vars": { "energy": 52, "mood": 58, "creativeUrge": 40 } },
  "sticker": { "id": "d6d2ed570f3d224c", "emotion": ["可爱", "呆萌"], "caption": "…", "intents": ["greeting"], "gesture": "stand" },
  "copy": { "lines": ["今天不想说话。", "风把云吹歪了。"], "keywords": ["云", "风"] },
  "background": "grid",
  "medium": "coloredPencil",
  "composition": "left-low",
  "pose": "sit",
  "objects": ["cloud", "cup"],
  "palette": "cool-ink",
  "signature": "蛋蛋",
  "density": 0.42,
  "wobble": 0.55,
  "draft": 0.35,
  "textBox": { "x": 0.08, "y": 0.12, "w": 0.42, "align": "left" }
}
```

**硬规则**

- `copy.lines` 1–3 句，总字数 ≤ 30，只写内心独白；不出现标题、日期、素材名、参数、`AI` 字样。
- `signature` 只写对角色自己的称呼，走 `signatureName` 参数；默认取角色 `displayName`，不同角色可不同。
- `objects` 至少 2 个来自 `copy.keywords` 词表命中；否则 plan 重抽（最多 2 次），仍不满足就判定生成失败。
- `seed` 决定全部随机；同一 plan 渲染结果一致。

## 4. 变化系统

维度池：

- 背景 10 种（纸类 5 / 非纸 5，满足「纸张不超过一半」）：
  白纸、牛皮纸、横线本、方格纸、旧纸折痕；桌面一角、墙面、布料、纯色卡纸、雨窗玻璃。
- 媒介 6 种：铅笔、彩铅、水彩、蜡笔、马克笔、混合。
- 构图 6 种：`left-low`、`center-bust`、`right-full`、`top-left`、`diagonal`、`back-view`。
- 景别 5 种：特写、半身、全身、背影、小比例。
- 姿态 7 种：站、坐、抱膝、睡、背影、挥手、探头（`lie` 已移除：整幅旋转后读不出「趴」，避免出现被裁掉的半个人）。
- 物件 24 种（含云、雨、窗、杯、灯、枕头、星星、花、鱼、贝壳、纸鹤、音符、书、笔、线团、气球、面包、月亮、水洼、伞、炸鸡、尾巴抱枕…）。

**约束随机**：心情 → 允许的背景子集 / 姿态子集 / 色调；表情包 → 姿态与道具候选；文案关键词 → 必有物件；最后在这些候选里抽。

**新颖性护栏**：台账保留最近 12 条 plan，候选若与任一条在「背景 + 构图 + 姿态 + 主物件」四项全同，则重抽（最多 8 次）。另设配额：连续 12 张里背景至少 8 种、媒介至少 4 种、构图至少 5 种；不足时优先抽未用过的。

## 5. 渲染管线（Canvas 2D）

页面默认 `1080×1440`（配置可改，画布与截图尺寸随 plan 走），按人画画顺序分层：

1. **纸底**：底色 + 底材纹理（横线/方格/木纹/布纹/雨滴），边缘做轻微不齐。
2. **构图草稿**：浅蓝灰细线，画角色外轮廓、地平线、主物件位置；只保留 35%–70% 线段（`draft` 控制），部分被后层盖住。
3. **墨线**：变宽笔触（中心线 + 宽度函数 → 轮廓多边形）；两端收锋、抖动、断线、出头、复线；线色不是纯黑（`#2b2a28` 一类）。
4. **上色**：填色整体偏移 2–6px、独立抖动、出界 2–5px；按媒介给质感（彩铅叠线、水彩多遍+干边、蜡笔齿纹、马克笔宽笔触、铅笔淡彩）。
5. **阴影/细节**：手绘排线、接触阴影、纸白高光（留纸，不画白颜料）。
6. **纸纹层**：程序化齿纹（值噪声+纤维）`multiply` α≈0.5，尘点 α≈0.2，折痕/胶带/污渍按需。
7. **手写文字**：逐字旋转 ±2–6°、缩放 0.94–1.06、基线抖动 ±3px、字距不均；墨色比线略淡。
8. **落款**：右下角，小字，整体歪 2–5°，不出血。

**角色**（参数化 Q 版，不依赖某一张图）

- 读 `ageGroup` 决定头身比（幼年 2.5 头身 / 少女 6.5 头身）。
- 读 `outfitId` 决定服装皮肤：`initial-maid` → 女仆；水手服 → 水手；未知 → 女仆兜底。
- 身份锚点固定（不随 outfit 变）：蓝发波波头 + 呆毛、鳍耳、鲸鱼尾 + 尾鳍、女仆头饰/围裙（女仆皮肤时）、星星发夹、圆脸大眼小嘴腮红。
- 表情：眼型（睁/弯/半眯/闭/小瞳孔）、眉、嘴、腮红、附加（泪/zzz/星星）。
- 姿态：四肢角度与躯干倾斜参数化；背影只画后脑+尾巴+背影轮廓。

**文字位置**：按构图算一个「安静区」（不压脸、不压主物件），可左/右/上方；行宽 ≤ 画面 42%，行数 ≤ 3。

### 5.1 视觉 v2：角色层与手绘质感（2026-11-15）

角色身份色固定在 `DAN`，不再跟随纸张调色板漂移：深蓝发 `#1d285e / #263574 / #3b5199 / #4b66ad`、发梢青蓝 `#9ed0ea`、藏青裙 `#242b5d / #35447a / #171c42`、奶白围裙 `#fbf7ee`、皮肤 `#fbeee8`、手 `#f3cec1`、腮红 `#efa9a5`。新增 `withAlpha / fillGradient / softShade / charHatch / gouache` 做半透明叠色、体积阴影与排线。

- **头发与头饰**：后发先画，压住身体后再画裙与手；后脑补大块后发与颈部发片；白荷叶边软帽围头一圈，压在刘海后面；藏青窄发箍 + 白细边 + 两侧小蝴蝶结；鳍耳带白膜与珍珠耳坠；星星发夹。
- **身体**：泡泡袖 + 白蕾丝袖口 + 手；手改为掌心 + 拇指 + 三道指缝，尺寸放大，不再像粉色拳套；站姿腿是有体积的填充腿形，白袜褶口 + 圆头玛丽珍鞋（鞋面/鞋底/搭扣/蓝结）；坐姿与抱膝腿单独落点；裙摆 `hemY = bodyH + 46` 遮住大腿。
- **尾巴**：鲸尾主体 + 两片尾鳍 + 尾脊珍珠链 + 小蓝结。
- **表情**：虹膜径向渐变、双高光、上眼睑压线、下睫毛；8 种心情的表情配置；半睁眼用「裁剪到眼白后压肤色」实现，不再出现横贯整张脸的白色方块。
- **表情包语义**：`plan.sticker.motif` 取 `heart / gift / mic / bottle / tear / star / shell / cup`，由 `drawStickerMotif` 在右手边重画成手绘小物，不贴原图。
- **纸面小稿**：页面边角留 2–3 组淡色速写（鲸尾、眼睛结构、贝壳螺旋、手部指节），像画者随手试笔。
- **绘制顺序**：地面影 → 后发 → 尾巴 → 腿 → 裙 → 围裙 → 头 → 手臂 → 表情包小物 → 挥手手臂覆盖层。挥手手臂最后再压一层，避免被长发盖住；背影不画手臂，只留一小截泡泡袖。
- **背景/媒介**：5 种纸类 + 桌面/墙面/布料/纯色卡纸；`objWindow` 带窗棂、窗台与雨丝；`objMoon` 有月相渐变与月坑；`objCandy` 有糖纸斜纹；`objPillow` 有压痕、布褶、布尖与流苏。物件缩放 0.88–1.08，不再抢角色。

### 5.2 视觉 v3：几何 chibi 角色层（仅兜底）

v2 之后继续在 `drawChibi*` 上改比例、眼睛、刘海、头饰、蝴蝶结、袖子、围裙、尾巴和鞋，得到一套纯参数化的 Q 版角色。它解决了「没有角色底稿时仍能画」的问题，但造型语言仍是椭圆与路径拼接：脸扁、眼白大、头饰像珍珠、裙摆容易成黑块，角色密度上不去。**这一层保留为缺图兜底，不再作为交付质量路径。**

### 5.3 视觉 v4：预生成手绘角色底稿 + Canvas 场景合成

v3 的上限证明「用几何图元拼一个高密度动漫角色」是路线错误，而不是某几个参数没调好。v4 改为：

- 角色底稿：从 `data/characters/packs/dandan-initial/03-child-initial-maid.png` 裁出正面参考，生成手绘彩铅 + 墨水线稿风的 chibi 立绘；要求保留深蓝渐变长发、白色蕾丝女仆头饰、蓝蝴蝶结、鳍耳、深蓝女仆裙、白围裙小鲸鱼刺绣、贝壳包、鲸尾、白袜蓝鞋。生成结果去白、裁透明内容后存入 `assets/draw/sprites/`，共 17 张，覆盖 8 种正面心情、4 种坐姿、2 种背影、抱膝、扒纸边、侧躺。
- 运行时：`drawSpriteCharacter` 按 `pose/mood` 选图，`drawImage` 以正常 alpha 合成，再叠加纸纹、阴影和手绘页码；`drawCharacter` 优先走精灵，缺图才回退 v3。
- 路由：`src/creative/draw/server.js` 提供只读 `/assets/draw/sprites/<name>.png`，文件名做白名单校验，不允许目录穿越；`drawAssetsPaths()` 返回 `spriteDir`。
- 资源归属：精灵是项目资产，随仓库分发，运行时不需要再下载角色包；`assets/draw/sprites/README.md` 记录许可与维护方式。

这样角色密度、表情和服装细节由手绘底稿保证，Canvas 只负责纸张、场景、文字、颗粒和落款，避免再用几何图元去追一个高密度动漫角色。当前剩余差异集中在 `peek` 纸边/构图边界、场景物件的精细度，以及真实宿主下点一次「立即触发一次」的端到端复核；Git 素材审计已完成，但尚未提交。

## 6. 与行为调度的接入

- `ACTIONS.create.executor = 'local-draw'`；`actionLimits.create` 沿用当前默认（2 次/天、120 分钟）。
- `ActionRunner.prepare('create')` 返回真实预览：这次心情、表情包、要画什么、存哪。
- `ActionRunner.start('create')`：
  - 同步返回 `{ok:true}` 并进入 `running`，绘制在后台跑；
  - 阶段写进 `activity.detail`（准备 → 起草 → 上色 → 文字 → 截图 → 保存）；
  - 成功 `finish('done', '画好了：…')`；失败 `finish('failed', 原因)`；`stop()` 取消并关闭标签页、不写半成品。
  - `canStop:true` 直到收尾。
- 自动：调度循环按 `policy` 走原逻辑：
  `auto` 直接 `executor.start`；`ask` 进 `pending` 等 `/pending/approve`；`off` 只记日志。
  手动：`trigger:'manual'`，不经过策略、不占自动次数（与 explore/social 一致）。
- 审批执行走 `/pending/approve` → `actionRunner.start(kind, {trigger:'approval', pending})`，与现有一致。
- 审批/自动执行使用**预览时落进 `payload.plan` 的那一份计划**，不再另抽一张：主人看到的文案、物件、构图和最终 PNG 一致；手动触发则用启动瞬间生成的计划。

## 7. 运行环境与离线

- 绘制在本地 HTML 页面里用 Canvas 完成，Node 只做三件事：起一个只读本地静态服务、开共享浏览器标签页、CDP 截图。
- 字体随包：`assets/fonts/LongCang-Regular.ttf`（Google Fonts Long Cang，SIL OFL 1.1，许可见 `assets/fonts/LongCang-OFL.txt`）。页面用 `@font-face` 从本地服务加载，不依赖系统字体。
- 纹理与场景仍程序化生成；角色使用随仓库分发的 `assets/draw/sprites/` 透明 PNG，不依赖外部图片、模型或 `E:\AI视频工具`。
- 共享浏览器来自 `platforms.getAdapter('douyin').hub`；画图页 `kind='draw'`，用完即关，不导航别人的标签页。

## 8. 产物与清理

- PNG：`<桌面>/大肥鱼创作-YYYYMMDD-HHMMSS-<mood>.png`（桌面目录可由 `decision.draw.desktopDir` 覆盖）。
- HTML：`data/creative/draw-YYYYMMDD-HHMMSS.html`（保留最近 30 份）。
- 台账：`data/creative/draw-index.json`，字段含 plan、png、html、耗时、结果；保留最近 60 条。
- 不写半成品：截图失败/取消时删临时文件。

## 10. 失败与取消语义

| 情况 | 活动状态 | 用户看到 |
|---|---|---|
| 模型超时/不可用 | 继续画 | 用本地兜底独白，不失败 |
| 角色库不可用 | 用内置身份锚点 | 正常画 |
| 表情包库为空 | 跳过语义参考 | 正常画 |
| 浏览器起不来 | `failed` | 「共享浏览器没起来，画不了」 |
| 截图失败 | `failed` | 原因 + 不产生 PNG |
| 用户停止 | `cancelled` | 关闭标签页、删临时文件 |

## 12. 验收样张

12 张：8 种心情各 1 张 + 4 张「同心情不同输入」（换表情包 / 换文案 / 换媒介 / 换背景）。
样张暂存 `data/creative/samples/sample-01.png` … `sample-12.png`（附 `_contact-sheet.png` 便于一次看完）。该目录属于运行时数据，按 `.gitignore` 不入库；验收后再决定是否单独归档。
要求：至少 8 张场景明显不同；不存在「背景+构图+姿态+主物件」四项全同；纸类 ≤ 6 张；落款可配置。

视觉现状：12 张已全部用 v4 角色底稿渲染。01 桌面坐姿、02 墙面雨线背影、03 墙面侧躺、04 卡纸挥手、05 横线本扒纸边、06 雨窗抱膝、07 卡纸得意、08 墙面全身、09 白纸背影、10 牛皮纸抱膝坐、11 方格纸对角、12 墙面侧睡。角色密度与旧稿同一量级，剩余差异集中在构图松紧、peek 纸边和部分精灵边缘白边。

## 14. 已知边界

- 角色底稿是**项目内预生成的手绘立绘**，不是运行时调用生图模型；它比几何参数化更接近真实形象，但仍不是逐笔写生，极端姿势/角度受现有 17 张底稿限制。
- 缺精灵文件时回退到 `drawChibi*` 几何角色，那一层只保证「还能画」，不保证达到交付质量。
- `peek-blank` 仍有一道浅白纸边；`sample-08` 的 `center-bust` 计划实际画成全身，属于构图参数偏差，尚未强制裁半身。
- 云、窗、气球、伞、笔、枕头等场景物件仍是程序化线稿，精致度低于角色底稿；如果需要整张都达到「优秀美术生」水准，物件层还要继续升级。
- 共享浏览器必须能启动；无 Chrome/Edge 的机器画不了（与抖音功能同一前提）。
- 文案模型未接上时用本地兜底句，文采有限但不阻塞。
