> 用户问：大肥鱼他们为什么那么像真人？有人私信会主动回复，人设、记忆、语言是怎么调的？

## 二、拆开看，像真人的四个零件

### 1. 主动回复（私信）
- 抖音官方的私信接口 2025 年 4 月已对开发者关闭（存量也在回收），所以社区全是**浏览器自动化**：本地 Chrome + patchright/CDP 挂着，轮询私信会话，发现新消息就生成回复发出去（dsh-feiyu 的抖音通道就是这么干的）。
- 回复不是秒回一句话就完：真人会**分条连发**（"在" → "刚看到" → "怎么啦"），会发表情包，会隔几秒。
- 我们现在的差距：**只做了手动/值班时操作**，没有"常驻监听私信 → 主动回"的循环。

### 2. 人设
- 不是一张"你是XX，性格XX"的卡，而是：
  - **身份锚点**（名字、称呼、来历）+ **状态**（心情/精力/亲密度）+ **立场**（对什么有意见）；
  - 人格会**变**（记住的事多了，偏好会漂）；
  - 关键：人设只管"怎么说话"，不管"知道什么"——没经历过的不编。
- 我们已经有：锚点人格 + 三层记忆 + 决策状态机（心情/精力），方向是对的；缺的是**把这些状态真正写进每轮对话**（现在只有时间）。

### 3. 记忆
- 社区做法：三层（主记忆 / 兴趣 lore / 私信记忆）+ **每日反思**（把当天聊天提炼成一句）+ 跨平台共享 + 按人隔离。
- 真人感的来源：**记得你上周说过什么**、记得"第一次见面"这种日期、记得在别的平台发生的事。
- 我们已经有：anchor / trait / episodic 三层、钉住、隔离、配额；缺的是**每天一次的主动反思**（现在靠对话触发）和**按人记忆**（私信对象级别）。

### 4. 语言
- 分条发（短句一条条来）、允许不完整、口头禅、语气词、表情包、颜文字；
- 不说"作为AI"、不列清单、不客服腔、不每句完整；
- 同一个人不同心情，说法不一样（状态注入）。
- 我们已经有：人格段的"说话的样子"硬规则、当前时间注入；缺的是**分条发消息**和**按对象调语气**。

| 私信常驻监听 + 主动回复 | ⏳ 未完成 | 浏览器侧消息入口还不稳（顶部「消息」浮层结构会变），且"回复生成"需要模型触发：DSH 的 `agentLoop.createAgent` 可以起 agent，但要在插件里接一套"监听→起会话→取回复→发出去"的闭环，工作量比前三项大 |

### 主动回复的下一步（方案已经想好）

1. 浏览器侧：`inbox.js` —— 打开消息浮层、读会话列表（未读标记/名字/最后一条）、点开会话、读最近消息、发送。入口用"顶部消息按钮 + 私信浮层"，多套选择器兜底。
2. 触发：插件内 `ctx.timer.interval` 每 30–60 秒检查一次未读；同一个人 10 分钟内最多回 2 次；0–7 点只回不主动。
3. 回复生成：优先用 `agentLoop.createAgent` 起一个轻量 agent（带人格段 + 这段消息 + 记忆），拿它这一轮的文字回复；拿不到就退回 duty 会话。
4. 发送：分条发出（已实现的拆条逻辑复用），发完写一条 episodic 记忆（"今天有人私信我…"）。

## 四、先不做的

- 不做"人气度/好感度数值条"那套（容易变成数值表演）；
- 不照搬别人的角色文本与措辞；
- 不让主动消息变成刷屏：所有主动行为都要有频率上限和开关。
