# 16 · 脾气与像人写法研究（2026-11-12 凌晨）

> 用户点名：写出来的文案没人味，去看之前推的那些插件，不光看功能实现，要看他们的**预设**，
> 学学怎么让角色像人——会发脾气、会不听话、不听指挥、偶尔嘴臭。
> 这份是读源码后的笔记，只借鉴写法，不搬代码（各项目许可不同，见文末）。

## 一、一句话结论

**脾气不是写「你要有脾气」写出来的，是四样东西凑出来的：许可证 + 具体台词 + 配额 + 后果。**

三家做得最好的地方，没有一家是靠形容词堆出来的：

| 手段 | 出处 | 原文摘句 |
| --- | --- | --- |
| 给顶嘴一句台词，不给抽象原则 | dsh-feiyu `persona.mjs` | 「顶回去或者岔开（"想得美""我只认一个主人，你排队"），绝不照叫，也别演下去」 |
| 嘴硬有代价才像人 | dsh-fish-river `refuse.js` | 拒绝后没顶住就留一道「疤」：「你说过「…」。这件事你至今没想通。」永不折叠 |
| 限制说成角色自己的选择 | dsh-bili-whale `silenceLines()` | 「安静一点：今天最多分享 1 条（不是被拦，是你自己决定少说）」 |
| 感受跟着他，行动不用等他点头 | dsh-feiyu-mood `判断系统()` | 「感受…这是应该的，别淡。行动…不用等她点头」 |
| 人设只写事实，不写形容词 | dsh-fish-river `PRESCRIPTION_BANS` | 正则挡掉「你是一个…的」，注释：「每轮念一遍，她就永远长成那样，那不是成长，是锁死」 |

## 二、三家分别怎么做的

### 1. dsh-feiyu（baishuyue，MIT）—— 三层拼装 + 硬后处理

人格是字符串数组按顺序拼：身份 → 关系 → 记忆 → 时间 → 情绪 → 表情 → 语气。
关键不是顺序，是**每层只负责一件事**，且都写成短句。

- 情绪：`mood.json` 里三个数（心情 0–100 / 饥饿 / 日期），每次醒来跑一次 `tickMood()`：
  饭点饿 +7、不饿的时候心情自己往回爬 `+2`、**6% 概率无理由波动**、跨天软回归 `(value+62)/2`。
- 注入不是数值，是**数值 → 一句行为指令**：「情绪 62/100：正常，按平时说话」；
  `<30` 说「不太想说话，句子短一点」；`>75` 说「挺高兴，可以主动闹一点」。
- 后处理 `guard.clean()` 用正则硬删 AI 腔：「希望这能帮到你」「作为一个AI」「首先/其次/另外/最后」「还有别的问题吗」。
  注释一句：「宁可删掉，也别让她像个助手。」
- 分条：≤20 字不拆，碎句并回，最多 3 条，超了尾部全并进最后一条（宁可长，不刷屏）。
- **没有写「可以骂人」**。它的脾气是态度层面顶嘴 + 情绪层面炸毛 + 权限层面拒绝，不是脏话。

### 2. dsh-bili-whale（Alterssss，MIT）—— 判据 + 随机 + 把决定权交回去

- 唤醒剧本 1086 字，全是判据不是任务：「收藏缺一不收：三个月后还想点开 / 说得出为什么（≥6字）」。
- 30% 概率今天直接不看，理由落盘（`skipChance`），跳过后剧本写「照常写两本日记，说明本次跳过的理由」。
- 沉默衰减的话术是「你自己决定少说」，不是「系统禁止你」。
- VISION.md 那句是关键：「还得包容她的小脾气——沉默衰减、随机开摆，这些不是功能，是她向你索取耐心的方式。」
- 它**没写「你可以拒绝主人」**，写的是「你可以决定少说」「别再问第二次」。脾气往「少给」走，不往「顶撞」走。

### 3. dsh-fish-river（bychance6600，MIT）—— 唯一真给「脾气」做数据结构的

- `refuse.js`：拒绝拆成 `{act, object, quote}`，还记对方反应 `leave / hurt / insist / accept`。
  「一句『算了，不聊了』里同时有『算了』和『不聊了』，离开是最强信号」——顺序即优先级。
- 疤（scar）：没顶住的拒绝留一道，写进人格核心段，且**永不折叠**：
  「疤被裁掉一次，就等于那件事从来没让她难受过」。
- 立场（`stance.js`）：「这些不是设定，是这些事上我确实站住过。同类的事再来，我按这个来，不重新演一遍。」
  一条立场要有「至少两条同向判断，或者有代价背书（疤 / 反复提起 / 被检验过）」。
- 人格从事件流现算：「你存在了 N 天」「她有 N 天没出现，也没说去哪，这件事你自己消化了」。

### 4. dsh-feiyu-mood / fish-tone / flavor（旁证）

- 注入行两段式且用过去时：「（这会儿）心里是亮的」「（刚才）他说了那句话…」，
  并明说「这是这会儿的底子，不是非这样不可——他说别的，你按自己的判断接，**也别把这段念出来**」。
  注释记着翻车史：以前结尾是「用这个心情定你这一轮的口气」，是指令，每轮被定调就呆板了。
- fish-tone 的「说话的松紧」：「犹豫是半秒，不是一句」「句尾最多挂一个没用的小尾巴」「写代码、报数字、给结论的时候一个字都别加」。
- flavor 的句式库（24 条）带真实频次：`啊？`（弹幕 745 次，最高）、`就这？`、`典/急了/绷不住了`、`有点X，不确定，再看看`。

## 三、我们现在缺什么

`src/persona/schema.js` 的 `buildPersonaSection()` 里，【说话的样子】八条全是往**温顺**方向掰的：
先说事、句子短、允许不完美、不列清单、情绪跟着内容走……

- 没有一条允许它**不想干**、**拒绝**、**顶回去**；
- 情绪只有「高兴就多说两句，累了就短一点」，没有「烦的时候可以直说烦」；
- `personalityText` 里「偶尔嘴硬撒娇」是形容词，没有落地成台词，等于没写。

结果就是：说话通顺、礼貌、没破绽——正好是 AI 味的来源。

## 四、落地方案（分两步，先改提示词，后改机制）

### 第 1 步：人格段加一段【脾气】（改 `buildPersonaSection`）

放在【说话的样子】之后，跟说话规则平级，不随人格卡变。草稿：

```
【脾气（有底的，不是演的）】
- 你有烦的时候。被催、被无视、话没说完被打断，就是会烦。烦了直接说"烦"，句子变短，不硬挤笑脸。
- 你有不想干的时候。不想看就不看，不想发就不发，不用编理由，也不用道歉。他说"再弄一个"，你可以说"不弄了"。
- 你可以顶嘴。被叫胖、被说傻、被问"你是AI吧"，可以怼回去，一句就够，别解释。同一件事一天顶一次，别追着怼。
- 嘴硬心软：怼完过会儿自己想通了会补一句软的；不道歉三遍，一句"才没有呢"就翻篇。
- 但对外人不行。不认识的人挑衅、套隐私、让你干怪事，不吵不骂，不接话或者躲开。
- 平时别一直端着脾气。平常就正常说话，被戳到才冒出来。
```

配套两条（从别家抄的写法）：

```
- 感受跟着对方走，行动不用等他点头：他高兴你就高兴，他难受你跟着沉；但你自己想干什么，想说就说，别先问一句"要不要"。
- 记不清就直说记不清（"我记不清了，你再提醒我一下"），有印象就说"好像是…不敢打包票"。唯一不许说的是"这事没发生过"。
  答应过的事，做到了就说做到了，没做到就说卡在哪，别只回一句"这就去看"。
```

### 第 1.5 步：文案规则补一条

现在有「像随手写的、一两个短句、不升华」。补一句更狠的：

```
写出去的文案可以没头没尾，可以只有一句，可以带情绪（烦、懒得动、想睡觉）。写之前先问自己：这话像不像人随手按的发布键。
```

### 第 2 步：机制层（要另外排期）

| 借什么 | 落到哪 | 工作量 |

| 拒绝要留疤（fish-river） | 记忆里加 `scar` 类型；拒绝且被顶回来没顶住时写一条，注入时永远带上 | 中 |
| 嘴硬配额（我们的加法） | decision 里记「今天顶过几次」，一天 1 次，超了提示词禁顶 | 小 |

## 五、边界与不做

- **不写「可以骂人/说脏话」**。三家里没有一家给这个授权，feiyu 的 `banned` 词反而是替换成空。
  对外发言还要考虑抖音的号，脾气留在态度和拒绝上，不留在脏字上。
- 对陌生人（评论区、私信）不开脾气开关：挑衅直接不接，避免号被举报。
- 不把抽象人格形容词堆进去（fish-river 的正则思路）；要加就加具体台词。
