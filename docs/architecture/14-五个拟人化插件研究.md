# 14 · 五个拟人化插件的研究笔记

> 用户点名：dsh-agent-md、dsh-feiyu-mood、dsh-fish-tone、dsh-speak-up、dsh-meme。
> 只借鉴思路，不复制代码；npm 上查不到的名字单独注明。

## 1. dsh-feiyu-mood（鱼的心情，Yuuyuko-uu / npm 0.9.2）

**它解决的问题**：AI 的心情不该是"开局设定 + 时间衰减"，而该是**每轮对话真的影响它**。

做法：
1. 每轮聊完（turn-stopping）把「用户说的 + 它回的」拿去问一次模型；
2. 模型返回四样：`moodDelta`（心情涨跌）+ 七根情绪各涨多少 + 一句理由 + `confidence`（这次判断有多确定）；
3. 心情值改动并记进时间线；**同一次变化只说一次**——把「刚才心里那一下」带给它；
4. 说心情走 `systemPrompt.context`（单独一段），不改系统提示本身，**不破坏前缀缓存**；
5. 设置里能改「怎么告诉它」：不告诉 / 只说心情 / 说它刚才那件事；可信度门槛可调；
6. 右下角挂饰点开看数值 + 情绪 + 时间线。

**我们能借的**：我们的「心气注入」现在是 decision 状态机（预设变量 + 衰减），可以升级成
「每轮结束后让模型判一次心情走向」→ 写回 decision 的 mood/energy，并记一条时间线。
这样它今天被夸 vs 被怼，情绪是真的不一样。

## 2. dsh-speak-up（主动搭话，Yuuyuko-uu / npm 0.3.1）

**它解决的问题**：没人在说话的时候，它也可能先开口。

做法：
1. 定时器到点；
2. 掷一次**本地骰子**（`Math.random`，一个 token 都不花）；
3. 没掷中：什么都不做，只留一条记录；
4. 掷中：往「目标会话」送一句话 → `agent.followup(message)` → DSH 自己开一轮，它的人格、历史、工具、记忆都照旧。

代价：只有掷中那一步才花模型。

**我们能借的**：我们缺的正是「主动开口」。
- 可以先落在 DSH 会话里：定时掷骰子，中了就 followup 一句（比如「你在忙吗」），或者触发一轮抖音活动；
- 注意频率：默认十几分钟一次、夜间降频，跟 whale 的「低频主动消息」一致。

## 3. dsh-meme（表情包，npm 0.1.80）

**它解决的问题**：表情包要能点、能搜、能让 AI 自己接梗。

做法：
1. 输入框旁 😊 一键发图：搜索、按图库/情绪筛选、悬停大图预览、点一张直接发送；
2. **AI 主动斗图**：按聊天情绪自己找图接梗，四档「关闭 / 看气氛 / 活跃 / 每轮都发」，提示词可改写；
3. 图库自己养：上传后说「把这张图入库」自动识别分类描述；拷贝进目录点「扫描新增」；GIF 走扫描保留动画；改名/删除后扫描清理失效记录；
4. 内置大肥鱼图库 24 张（开箱即用）；
5. 多图库开关、ZIP 导入导出、市场安装。

**我们能借的**：我们的表情包已有库 + 远程装包，但没有「主动发表情」和「点图发送」。
- 抖音值班时按心情挑一张表情发（我们已经手动验证过私信发图可行）；
- Web 端可以加表情选择器（选图 → 插进发送内容）。

## 4. dsh-agent-md（wwsmiler1-bit，GitHub ★70，Go 上搜到的正确版本）

**它解决的问题**：人格不该锁死在代码里，应该像 VS Code 的 AGENT.md 那样——**Markdown 写、全局一份 + 项目一份、可视化编辑**。

做法：
1. 设置 → 人格：顶部一行「本会话当前生效」（此刻吃哪份文件、多少字，全局与项目一起算）；两个页签「全局人格 / 项目人格」+ Markdown 编辑器；
2. **三层文件优先级**：`<项目>/AGENT.md`（跟仓库走、可提交 git）> `<DSH_HOME>/agents/projects/<目录名-哈希>.md`（本机，设置页编辑）> `<DSH_HOME>/AGENT.md`（全局底座，默认一起注入）；
3. 生效时机：`systemPrompt.context({ text: (context) => … })`，**只在渲染文本变化时重新追加**——改完下个回合生效，稳定前缀缓存不会被打断；
4. 「不同项目不同人格」天然成立：注入函数自己读 `context.agent.session.header.cwd`；
5. 写法：`# 你是谁 / # 语气与风格 / # 行事偏好 / # 边界` 分节就够；`<!-- 注释 -->` 不进上下文（省 token、防示例被当成设定）；`{{xxx}}` 自动降级成 `{xxx}`（防模板变量解析失败）；
6. 底部有**注入记录**（`<DSH_HOME>/agents/inject-log.jsonl`）——「到底生效没有」不靠猜；
7. HTTP 接口：state / save / create / config / open / register / pick；写文件带 `.bak`、单文件 512KB 上限、注入正文 40000 字截断。

**我们能借的**：把「人格 + 行为准则」从 JSON/硬编码迁成 Markdown 文件，设置页可编辑、注入记录可查。
我们的抖音值班指南 `prompts/douyin-duty.md` 已经是一个 Markdown 文件，缺的是「网页上能改 + 改了立刻生效 + 能看到注入了哪份」。

## 5. dsh-fish-tone（MX3a48c5，GitHub ★33）

**它解决的问题**：把话往人的方向掰一点点——不是靠人设，是靠**后处理**。

两个包：
1. `dsh-fish-tone`（人味插件，默认开）：**犹豫半秒、句尾挂个没用的小尾巴、带一份「无用度」统计**；
2. `dsh-fish-tone-flavor`（性格附属包，默认关）：可爱 / 抽象 / 热梗，77 条梗 + 24 个句式。

关键设计：
- **主包只管「像人说话」，性格是偏好不是语言能力，所以拆出去**：不装附属包，主包一个字都不变；
- 工具：`fish_tone({text})` 轻掰一档、`strength: "max"` 会塞一句废话、`fish_grammar({text})` 只报语病不改；
- 系统提示多一节「说话的松紧」；设置页「设置 → 人味插件」；
- 方法来自 B 站公开视频，语料是公开评论弹幕，报告只有聚合统计。

**我们能借的**：
- **发送前掰一档**：抖音评论/私信发出前过一道「人味改写」（加犹豫、加小尾巴、删 AI 腔），比只在提示词里要求更稳；
- **无用度统计**：量化"废话比例"，拿来调提示词；
- **性格分层**：说话能力（人人都有）和性格偏好（可换）分开，正好对应我们的「说话的样子」和「人格卡」。
