## 二、这一轮修掉的

### 1. 隐私测试误报：Git 不在 PATH

- 现象：`test/privacy.test.js` 用 `execFileSync('git')`；Windows 桌面启动的 Node 子进程 PATH 可能没有 Git，导致「忽略规则」全部误报为失败。
- 修法：测试自动尝试 `GIT_BIN`、PATH、常见安装位置（Windows 的 Program Files / LocalAppData，Unix 的 `/usr/bin/git` 等）；找不到时显式 `skip` 并给出原因，不伪装成通过。
- 同时新增「模板底图属于本地素材，不进仓库」断言。

### 2. 模板底图与文档冲突

- `docs/architecture/11` 与 `test/card.test.js` 都说模板底图不进仓库；`.gitignore` 却放行 `data/templates/**`，`data/share/README` 也说图片保留模板。
- 修法：移除 `data/templates/**` 放行，模板底图与头像留在本机；`data/share/README`、`CHANGELOG`、`README` 同步改成「本地素材，不随仓库分发」。
- 影响：`src/image/card.js` 在没有模板时走纯色渐变回退；卡片测试在无模板时本来就会跳过模板用例。

### 3. 素材许可被 README 的 MIT 表述盖住

- `README` 写「代码 MIT，可以商用」，但 `assets/icon.png`、`assets/avatar.png` 是 CC BY-NC-SA 4.0 同人立绘。
- 修法：根 README 明确区分「代码 MIT」与「素材单独许可」；新增 `assets/README.md`，写清来源、署名、非商业、相同方式共享；`THIRD_PARTY_NOTICES` 增加推荐表情包索引条目并链接到素材说明。
- 没有替换素材：替换会改变角色形象，属于需要负责人决定的事；当前按「个人本地自用」明确边界。

### 4. SECURITY 的登录态路径过期

- 旧文写登录态在 `data/platform/douyin-session.json`；现在主登录态在共享 Chromium 档案 `data/browser-profile/`，另有加密快照。
- 修法：表格改成「浏览器档案 + 加密快照」；视频画面说明区分「运行时只在内存」与「测试/调试截图可能落工作区但被忽略」。

### 5. npm 包缺运行所需 data

- `package.json` 的 `files` 只列了 `src/prompts/persona/locale/assets`，没带 `data/share`、核心人格和公开设置；按包安装时首次配置会缺少示例。
- 修法：加入 `data/share/`、`data/persona/core-persona.json`、`data/state/platform-settings.json`，并带 `SECURITY.md` 与 `THIRD_PARTY_NOTICES.md`。

### 6. PowerShell 子进程 ENOENT

- `src/image/card.js`、`src/platform/douyin/clipboard.js` 直接写 `powershell.exe`；某些 Node 子进程 PATH 不含 System32，卡片生成测试报 `spawnSync powershell.exe ENOENT`。
- 修法：新增 `src/utils/powershell.js`，优先尊重 `FISH_POWERSHELL`，再从 `SystemRoot` 找 Windows PowerShell，最后回退 PATH；三处调用统一使用它。

### 7. 设置补丁的原型链键

- 网页 `PUT /platform-settings` 会先做深合并；补丁里若带 `__proto__` / `prototype` / `constructor`，不应参与合并。
- 修法：`settings.js` 的 `deepMerge` 与 `config.js` 的 `merge` 丢弃这三类键，并加回归测试检查全局 `Object` 原型未被污染。

### 8. 文档与测试命令

- `README` 原来推荐 `node --test`（并行）；浏览器/临时目录相关用例并行时容易互抢资源。
- 修法：`package.json` 的 `test` 脚本改成串行；README 说明原因。
- UI 里的昵称占位从真实作者昵称改成中性的「比如 小鱼」。

### 9. 「活人配置」没有被 Git 卫生排除

这一轮唯一从 Git 移除的是 `data/templates/` 的图片素材，**没有动人格和配置基线**。用 `git check-ignore -q` 逐个核对，下面这些仍是可见文件：

- `data/persona/core-persona.json`：当前实际人格；
- `data/state/platform-settings.json`：当前实际平台设置；
- `persona/default-persona.json`：重置用默认结构；
- `persona/presets/voice-default.json`：出厂语气预设；
- `data/share/**`：示例人格、示例设置与记忆样本。

仍然忽略的是运行痕迹：`data/memory/`、`data/persona/audit.jsonl`、`data/state/decision.json`、`data/state/douyin-*.json`、`data/browser-profile/`、`data/plugin.log`。这些是私密记忆、登录态或本机日志，不属于「别人下载后能直接继承的配置」。

## 三、故意留着的

| 事项 | 原因 | 对开源的影响 |
| --- | --- | --- |
| `assets/icon.png` / `avatar.png` 仍是 CC BY-NC-SA | 替换会改变角色形象，需负责人决定；当前明确标注非商业 | 代码可 MIT；素材不能商用。README / assets/README / NOTICE 三处一致 |
| `data/persona/core-persona.json` 带 `ownerAddress: 老蛋蛋` 等个人化设定 | 这是当前人格，公开它是「可继承养成」的一部分 | 若不想公开个人称呼，需要在发布前另做一份脱敏人格 |
| `data/state/platform-settings.json` 带作者公开抖音身份与当前开关 | 已确认是公开示例配置，不是泄漏 | 新用户会继承这组开关；首次配置页可改 |
| `data/templates/` 留在本机 | 来源/许可未逐张登记，且卡片有纯色回退 | 仓库不附带模板图；卡片功能仍可用 |
| `publish.js` 仍保留但不接入口 | 发作品功能需重新设计 | 属未接线参考代码，不产生行为 |
| `docs/architecture/17` 的 Windows 用户目录占位 | 审计记录里的示例路径 | 已改成占位，不是本机真实路径 |
| 真实私信/浏览器验证未在本轮重跑 | 需要登录态和抖音页面，且会对外发消息 | 本轮只做静态/单元/打包验证；对外行为未重新实测 |

## 四、Git 收尾建议（需要负责人审查后才执行）

当前仓库状态是「有 `.git`、`master` 没有任何提交、所有文件未跟踪」。本轮**没有执行 `git add` 或 `git commit`**，以免绕过「提交前必须负责人审查」的约定。

建议首个提交按下面顺序审查：

1. `.gitignore` / `.gitattributes` / `.env.example`
2. `LICENSE` / `README.md` / `SECURITY.md` / `assets/README.md` / `docs/legal/THIRD_PARTY_NOTICES.md`
3. `package.json`
4. `src/`（尤其 `utils/powershell.js`、`platform/settings.js`、`config.js`、`gui/web/index.html`）
5. `test/`（`privacy.test.js`、`platform-settings.test.js`）
6. `data/share/`、`data/persona/core-persona.json`、`data/state/platform-settings.json`
7. `docs/` 与 `CHANGELOG.md`

确认后再 `git add` 和首个 commit；提交信息建议：

```
chore: 初始化 dsh-fish-dandan 开源仓库

- 补齐 MIT 代码许可与 CC BY-NC-SA 素材边界
- 模板底图/头像改为本地素材，不随仓库分发
- 修正共享浏览器登录态说明与 npm 包内容
- 修复隐私测试的 Git 定位、PowerShell 定位与设置补丁原型链键
```
