# 08 · 代码审计与修复记录（2026-11-11 晚）

> 起因：用户反馈「点停止没反应、浏览器没关」「一直在刷精选、不会换推荐页」，并要求把项目整体审一遍、能优化的优化、文档更新。
> 方法：刷抖音链路由主线程逐行读代码 + 真实浏览器验证；其余模块派 3 个只读子代理（记忆/人格、决策/GUI、平台适配）出问题清单，主线程逐条对照源码核实再动手。**子代理只读，不改文件、不跑测试**。

## 一、本轮修掉的（都已验证）

### 刷抖音链路（真实浏览器验证）

| 问题 | 根因 | 修法 |
|---|---|---|
| 一直停在「精选」 | `openRecommend()` 只在 `header` 找顶部 tab，新版推荐入口在左侧导航第二个 | 等导航出现 → 点 `a[href*="recommend=1"]` → 等 `feed-active-video` 就绪；失败才报错，不静默 |
| 刷了但读不到视频 | 推荐页 URL 是 `/?recommend=1`，没有 `/video/<id>` | id 从 `[data-e2e="feed-active-video"]` 的 `data-e2e-vid`（或 class `video_<id>`）取 |
| 读到上一条的文案/作者 | 推荐页 DOM 同时挂多条 feed，全局 `querySelector` 命中已滑走那条 | 文案/作者/互动数都锁在活动 feed 的 `feed-item` 内读 |
| 围观时长算错 | `playbackState` 取全页第一个 `video`（预加载的） | 锁活动 feed 里的 `video`；`currentVideoId` 同步改 |
| 翻页不稳 | 只看 URL 是否变化，推荐页 URL 永不变 | 优先点 `[data-e2e="video-switch-next-arrow"]`，按 id 变化判断 |
| 点停止没反应、浏览器不关、界面卡住 | 只写标志 + 25 秒后 `child.kill()`，只杀父进程；`running` 仍为 true | 2 秒后 `taskkill /T /F` 整棵树 + 按 `browser.pid` 关 Edge + 5 秒兜底结算；snapshot 加 `stopping`，前端显示「正在停止…」并轮询收尾 |
| 关注/点赞/收藏/评论在推荐页点不到 | 选择器只覆盖详情页 | 补 `feed-follow-icon` / `video-player-digg` / `video-player-collect` / `feed-comment-icon`，点击优先在活动 feed 内找 |
| 转发/私信作用在错误的视频上 | 用推荐页 URL 打开，等于回到首页 | 用 `videoId` 拼 `/video/<id>` 详情页 |

实测：连续读 3 条不同视频，id / 作者 / 文案 / 点赞数正确，播放进度取到真实时长（10.4s、17.1s）；假 CLI 下 `duty.stop()` 2.2 秒内 `running=false`。

### 记忆

- JSONL 后端的 `updateLifecycle` 只改内存 → 现在追加生命周期补丁行并在加载时回放；pin/归档/访问计数/重要性不再重启回退。
- JSONL 的 `setMeta` 只写内存 → 落 `*.meta.json`，每日配额与复盘时间不再丢。
- `unpin` 只清 `pinned` 不降 `tier` → 现在降为 `trait`。
- 有 query 的召回用 `score > 0` 过滤（重要度/新鲜度恒正，等于没过滤）→ 改用 `relevance > 0`。
- `/(?:喜欢|爱)/` 会命中「不喜欢」→ 加负向后行断言。
- 自动捕获的 `conversation`/`auto` 系统标签被当兴趣统计 → 排除。
- 每日配额用 UTC 日期 → 改用 `localDateKey`。

### 人格

- 微调「太安静了」无条件 `sign = -1`（方向反了）→ 按极性词取反。
- 删掉 `degreeTokens` 死代码。

### 决策 / GUI

- `clampVars` 每 tick `Math.round`，把 0.03/分 的慢增量抹成 0（精力回不满、状态机几乎不切）→ 内部保留两位小数，页面展示时取整。
- 人工 nudge 过期后不清 → `activeOverride()` 就地清理。
- 调度参数只存内存，界面说「已保存」重启回默认 → 写进 `persistable().settings` 并在构造时回放；只在参数真变化时重算 `nextWakeAt`。
- `/pending/approve` 先摘除再执行，抛错就永久丢 → 抛错时 `restorePending()` 放回队列。
- 设置页可被 iframe 嵌套 → 加 `X-Frame-Options: DENY` + CSP `frame-ancestors 'none'`。
- 来源校验只看 `Origin.host === Host`，DNS rebinding 可绕过 → Host 必须是 localhost/127.0.0.1/[::1]；局域网 Host 只在显式 `allowRemote` 时才放行。
- 撤销一句话微调只回滚前端 → 撤销时重新保存服务端。
- 记忆列表加载无序号，慢响应覆盖新结果 → 加请求序号，只认最新一次。

### 平台适配

- 登录态密钥：`machineSecret()` 用了 `os` 但文件没导入，异常被裸 catch 吞掉，**所有机器共用固定密钥**且日志仍报 `machine` → 补 `import os`，降级时显式告警。
- 登录成功相位永不复位，导致过期后下次查询又显示已连接 → 改用会话 `savedAt` 比上次探测新来判断「刚扫码」。
- 保活探测无单飞、`lastProbeAt` 在结果前更新 → 单飞 + 完成后再记时间；网络错误不再误报「登录过期」。
- 插件卸载只停刷流定时器，登录浏览器泄漏 → `dispose()` 同时 `loginFlow.dispose()`。
- 出站发送与记忆写入共用一个 try，记失败会被当发送失败（重试会重复发）→ 记忆写入单独 try。
- `importCookies` 遇到数组里的 `null` / 无名字项直接 TypeError，且不按域过滤 → 逐项清洗、只留 `douyin` 域。
- 点赞数解析为 0 时，收藏/转发/评论绝对值被当比率（2000 收藏 = 2000%）→ 无点赞基数时不加比率分。
