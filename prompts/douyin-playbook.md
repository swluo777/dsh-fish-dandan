# 抖音操作手册 · 每个动作怎么做（值班前先看）

这里是**验证过的操作路径**。找不到按钮时先照这里来，别重新猜、别乱点。
发现更好的路径就改这里——改完下一次值班按新的来。

> 更新：2026-11-12 凌晨

## 通用规矩

- 播放器容器永远是 `[data-e2e="feed-active-video"]`，点赞/收藏/评论都在它里面找。
- 点之前先滚动到可见；点完等 1 秒再确认状态。
- 找不到元素时先确认：是不是在视频页？有没有弹窗挡着？评论面板开了没？
- **别硬凑**：一个动作试两次不行就跳过，记一笔「没找到」，不要瞎点。

## 点赞

1. 在播放器右侧竖排找：`[data-e2e="like-icon"]`，退路 `button[aria-label*="点赞"]`，再退到文字含「点赞」的按钮。
2. 已点赞的样子：aria-label 变成「取消点赞」，或 `[data-e2e="like-icon"]` 带精确的 liked / is-digged 标记。
3. 点完等 1 秒，再看一眼 aria-label 确认真的点上了。
4. **点赞经常点不上**（平台对点赞管得比收藏严）：点两次状态都没变就跳过，别反复点，记一笔「这次点赞没成」走人。

## 收藏

1. `[data-e2e="collect-icon"]`，退路 aria-label 含「收藏」/「取消收藏」。
2. 同点赞：点完确认状态。

## 评论

**评论框在评论面板的右下角**：一个可编辑区，里面有灰字「留下你的精彩评论吧」，右边是 @ 按钮。
面板没打开时，这个输入框根本不在页面里。

1. 先点右侧竖排的评论图标打开面板：`[data-e2e="comment-icon"]`。
2. 输入框不要死认某个 `data-e2e`：找**视口里最靠下的那个可编辑区**
   （`[contenteditable="true"]` 或 `textarea`，宽度 > 120、高度 > 12），它在面板底部。
3. 真实点进去 → 输入文字（不用改 innerText，那样按钮还是灰的）。
4. 输入完点面板里的「发送」按钮；找不到就按 Enter。
5. 坑：不打开面板直接找输入框一定找不到；固定选择器会改版，按「最靠下的可编辑区」找最稳。
6. 设置里开了「艾特主人」时，工具会先输入 `@` 再从下拉里选主人，正文要写成对主人说的话；没有在列表里选上会直接失败，不会把半截 @ 发出去。

## 关注（暂不开放）

## 回复评论

1. 评论条目：`[data-e2e="comment-item"]`（退路 `.comment-item`）。
2. 条目里的作者/内容：`[data-e2e="comment-username"]`、`[data-e2e="comment-content"]`。
3. 回复入口：条目里的「回复」按钮；点开后同样在面板底部输入框里写。

## 私信

1. 会话列表：`.imContainer`，条目 `.conversationConversationItemwrapper`。
2. **绝对不要点会话条目**——会触发验证码。读列表就够了。
3. 回复私信（打开会话后）：输入框 `.messageEditorinputArea` → 填字 → 点面板里的「发送」。
4. 发图：剪贴板放图片 → 点输入框 → Ctrl+V → 出现「发送给 xxx」弹窗 → 点「发送」。

## 改昵称 / 签名 / 头像

- **网页版个人主页没有改昵称的入口。** 别在 `/user/self` 上瞎找。
- 正确位置：`creator.douyin.com`（创作者中心）→ 账号设置 / 个人资料 → 编辑昵称、签名；头像也在那边。
- 改资料可能触发短信验证——所以能不改就不改；要改之前先看提示，别连点。

## 发布图文（暂不开放）

- 这个功能已整体关闭，当前没有发布工具，不要尝试；等主人重新设计后再开。

## 看自己的主页

- 自己主页：`/user/self`；别人的：`/user/<sec_uid>`。
- 主页上的作品列表、获赞、关注数都能读；读不到就刷新一次再读。

## 看主人主页的喜欢列表

- 只用工具 `douyin_owner_likes`，不要用 `douyin_open` 乱点别人主页。
- 主页的「喜欢」页签在页面上半部分；工具会自己点。
- 开着：只把新增的视频标题/列表面截图交给你理解；没有新增就不用写记忆。
- 锁着：工具返回 locked；只记「主人喜欢列表锁着」，不要猜里面有什么，也不要试图绕过。
- 这是主人的私事：不在公开评论、陌生人私信里提；只在和主人相关的话题里用。

## 翻推荐流

1. 回推荐流：点左侧导航「推荐」（`a[href*="recommend"]`）。
2. 换视频：键盘 ↓ 或鼠标滚轮；也可以点右侧「下一个」。
3. 判断当前是不是视频页：页面上有 `[data-e2e="feed-active-video"]`。
